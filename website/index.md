# EMBL-EBI AI-readiness criteria

A framework for judging whether a biological data resource is ready to be used in AI and
machine-learning work.

## How it is organised

- **[Principles](principles/index.md)**: nine areas of readiness, such as quality,
  accessibility, provenance and governance.
- **[Criteria](criteria/index.md)**: concrete, checkable requirements. Each criterion belongs
  to one principle, is a **MUST** or a **SHOULD**, and says how to assess it, what evidence to
  collect and how often to check it.
- **[Assessment objects](objects/index.md)**: what a criterion is checked against, such as a
  dataset, an API or a single record.

## Machine-readable data

Every criterion, principle and assessment object is also available as JSON-LD in the
project repository. The identifiers currently use a placeholder namespace
(`example.org`) and are not yet persistent.
